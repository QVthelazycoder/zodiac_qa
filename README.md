# zodiac_qa

## Giới thiệu
`zodiac_qa` là một dự án Python dạng bài tập/đồ án (phiên bản final trong thư mục `zodiac_qa_final_CS217.Q11`) liên quan đến hệ thống hỏi đáp (question-answering) về chủ đề cung hoàng đạo (zodiac). Dự án này có thể bao gồm mã nguồn, dữ liệu và các script hỗ trợ nhằm xử lý, huấn luyện hoặc đánh giá mô hình QA phục vụ mục tiêu học thuật.

> Lưu ý: README này viết bằng tiếng Việt để thuận tiện cho người đọc/tác giả dự án. Nội dung mô tả được giữ tổng quát — hãy chỉnh sửa lại phần "Hướng dẫn sử dụng" nếu trong repo có tên file hoặc lệnh chạy cụ thể.

## Những gì có trong repo
- Thư mục chính liên quan: `zodiac_qa_final_CS217.Q11/` (phiên bản cuối cùng của bài tập/đồ án).
- Mã nguồn bằng Python (ngôn ngữ chính của repo).
- Có thể bao gồm các file dữ liệu trong thư mục con `data/` bên trong `zodiac_qa_final_CS217.Q11/`.

## Yêu cầu
- Python 3.8+ (hoặc phiên bản Python tương thích với mã trong repo).
- Các thư viện phụ thuộc (nếu có) thường được liệt kê trong `requirements.txt`. Nếu repo chưa có, cài đặt thủ công theo lỗi khi chạy.

## Cài đặt (mẫu)
1. Tạo môi trường ảo:
   - python -m venv venv
   - source venv/bin/activate  (Linux/macOS) hoặc venv\Scripts\activate (Windows)
2. Cài dependencies (nếu có file `requirements.txt`):
   - pip install -r requirements.txt
